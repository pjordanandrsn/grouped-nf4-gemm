# Code of conduct

## The short version

Be straight with people. Argue with the work, not the person. Bring evidence.

This project's review culture is unusually blunt about numbers — claims get
challenged, results get retracted, and "your measurement does not reproduce" is
a welcome issue rather than an insult. That bluntness is aimed at **claims**.
It is never a licence to be unpleasant to a person.

## Expected

- Assume good faith, including from people whose report is wrong.
- Say what you measured and how. Disagreement backed by a receipt is the most
  useful thing anyone can bring here.
- Accept correction the way this repo does it: fix the claim, say what changed,
  move on. Errata are normal and are not a mark against anyone.
- Respect that a maintainer's time is finite and unpaid.

## Not accepted

Harassment, personal attacks, demeaning comments, or sustained disruption.
Publishing someone's private information. Sexualised language or imagery.
Deliberately wasting reviewer time — including submitting AI-generated
"contributions" nobody has read or run.

## Scope

Applies in issues, pull requests, discussions, commit messages, and anywhere
someone is representing this project.

## Enforcement

Report to `security@cerinamroth.com` — the same private channel as
[SECURITY.md](SECURITY.md), because it is the one address that is monitored and
encryptable. Reports are handled privately.

The maintainer may edit or remove contributions, or block accounts, for
behaviour that violates this document. Where a response is not obvious, the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
enforcement ladder is the reference — correction, warning, temporary ban,
permanent ban.

## A note on AI-assisted contributions

They are welcome and this project uses them openly: commits carry
`Co-Authored-By` and an AI-disclosure trailer by default. The bar is unchanged —
**you** are the author, you have read and run what you are submitting, and the
claims carry receipts. An unreviewed dump fails on the second point, not the
first.
